# apps/wix-app — Wix integration (placeholder)

This directory is a placeholder. The Wix app is **generated by the Wix CLI**, not hand-
authored, so it's deliberately empty until that step. Two embed paths (see PLAN.md → "Wix
integration"):

## A) iframe embed (ship first)

No code here. Deploy `apps/web`, then in the Wix Editor add an **Embed / HTML iframe**
element pointing at the deployed URL. The web app already posts its height for auto-resize
(`apps/web/lib/iframe-resize.ts`); add the matching listener on the Wix side.

## B) Native custom-element site widget

Generate the Wix app into this folder when ready:

```bash
cd apps/wix-app
npm create @wix/app@latest .          # unified Wix CLI (Astro-based)
npm run generate -- # choose: site widget (custom element)
```

Then, inside the generated widget, use the **Convex React client** (point it at your Convex
deployment URL) and reuse the same `Uploader` / `JobView` logic as `apps/web`. Convex
handles CORS/origins, so no separate API layer is needed.

> Kept out of the pnpm workspace until generated (the Wix CLI manages its own deps).
